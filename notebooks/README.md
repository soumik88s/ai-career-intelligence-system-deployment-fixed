# Research & Prototyping Notebooks

This directory contains Jupyter notebooks used for research, exploratory data analysis (EDA), model training, evaluation experiments, and viva demonstration artifacts.

## Notebook Structure
1. **`01_eda_and_baseline.ipynb`**: Dataset exploration, term frequency analysis, and baseline TF-IDF cosine matching.
2. **`02_sbert_embedding_experiments.ipynb`**: Sentence-BERT embedding comparisons (MiniLM vs BERT-base vs MPNet).
3. **`03_hybrid_scoring_optimization.ipynb`**: Multi-factor weight tuning, correlation analysis, and ATS compatibility scoring logic.
4. **`04_shap_explainability.ipynb`**: SHAP feature importance visualizations for explainable AI.
5. **`05_evaluation_ndcg_mrr.ipynb`**: Information Retrieval evaluation (NDCG@K, MRR, Precision@K, F1-Score).
