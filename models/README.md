# Models Directory

This directory holds serialized model artifacts, tokenizers, fine-tuned Sentence-BERT checkpoints, and vector index files.

## Directory Layout
- `checkpoints/`: Fine-tuned BERT weights and custom loss checkpoints.
- `vector_index/`: Saved FAISS index files for fast nearest-neighbor job retrieval.
- `vectorizer/`: Saved TF-IDF vectorizers and N-gram vocabulary dictionaries.
